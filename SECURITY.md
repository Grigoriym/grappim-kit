# Security Policy

## Supported versions

Only the latest published `io.github.grigoriym:grappim-kit-*` release receives security
fixes. Please reproduce against the latest version before reporting.

## Reporting a vulnerability

**Do not open a public issue for security problems.**

Report privately through GitHub:
[Security → Report a vulnerability](https://github.com/Grigoriym/grappim-kit/security/advisories/new).

Please include:

- the affected module(s) and version,
- a description of the issue and its impact,
- steps to reproduce or a minimal proof of concept.

All communication happens in the GitHub advisory. Reports will be acknowledged on a
best-effort basis; this is a personal project maintained in spare time. There is no bug
bounty.

## Scope

This policy covers the code in this repository. Issues in a consuming app
(TaigaMobileNova, wallosmobile, wayprint, HateItOrRateIt) should be reported in that
app's own repository, unless the root cause is in a `grappim-kit` module.
